# NFT Store dApp

Учебный проект — распределённое приложение (dApp) для магазина NFT,
построенное на базе Scaffold-ETH 2.

## Стек

- **Scaffold-ETH 2** — шаблон для dApp
- **Next.js** — фронтенд
- **Hardhat** — среда для смарт-контрактов
- **Wagmi / Viem** — библиотеки для работы с блокчейном
- **TypeScript** — язык
- **Solidity** — язык смарт-контрактов

## Структура

\`\`\`
contracts/                    # смарт-контракты
  YourNFT.sol                 # ERC-721 для создания NFT
  NFTStore.sol                # магазин: продажа и покупка
deploy/                       # скрипты деплоя
  01_deploy_contracts.ts
packages/nextjs/              # фронтенд
  app/page.tsx                # главная страница — витрина + форма mint
  components/NFTList.tsx      # компонент выставления на продажу
\`\`\`

## Смарт-контракты

### YourNFT.sol

ERC-721 контракт для создания NFT. Функция `mint(uri)` создаёт новый
токен и привязывает к нему URI с метаданными.

### NFTStore.sol

Контракт магазина. Позволяет:

- `list(nft, tokenId, price)` — выставить NFT на продажу (эскроу)
- `buy(listingId)` — купить NFT за указанную цену
- `getAllListings()` — получить все активные лоты

## Как работает

1. Пользователь создаёт NFT через `YourNFT.mint()`.
2. Выставляет его на продажу через `NFTStore.list()` — токен переходит
   в эскроу контракта.
3. Другой пользователь покупает через `NFTStore.buy()`, оплачивая ETH.
4. NFT переходит покупателю, ETH — продавцу.

## Фронтенд

Главная страница (`page.tsx`) содержит:

- форму mint — создать новый NFT по URI
- витрину — список активных лотов с кнопкой «Купить»
- подключение кошелька через Wagmi

Взаимодействие с контрактами через хуки Scaffold-ETH 2:
`useScaffoldReadContract` и `useScaffoldWriteContract`.

## Запуск

yarn install
yarn chain      # запуск локального блокчейна
yarn deploy     # деплой контрактов
yarn start      # запуск фронтенда
